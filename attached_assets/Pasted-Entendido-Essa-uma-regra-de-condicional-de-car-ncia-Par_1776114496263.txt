Entendido! Essa é uma regra de condicional de carência. Para o sistema "conversar" com o agendamento e o horário do cancelamento, precisamos de uma lógica que compare dois tempos: o Horário de Início (Agendamento) e o Horário de Cancelamento.Aqui está como vamos estruturar essa inteligência no sistema:1. Panorama da Solução (Lógica de Carência)O sistema deve calcular a diferença de tempo: $HorárioAgendamento - HorárioCancelamento$.Regra A (Cobra): Se o cancelamento ocorreu depois do agendamento ou até menos de 2h antes.Ação: Aplica tabela "Cancelada" (ou 100km) + Pedágio R$ 35,00.Regra B (Não Cobra): Se o cancelamento ocorreu com mais de 2h de antecedência.Ação: Valor Final = R$ 0,00 e Pedágio = R$ 0,00.2. Implementação no Motor (lib/financialUtils.ts)Vamos adicionar este cálculo de tempo para que o faturamento seja automático:TypeScript/**
 * REGRA DE CARÊNCIA PARA CANCELAMENTO
 */
const calcularCustoCancelamento = (mission, financialData) => {
  const agora = new Date();
  const horarioAgendamento = new Date(mission.scheduled_at);
  
  // Calcula a diferença em milissegundos e converte para horas
  const diffHoras = (horarioAgendamento.getTime() - agora.getTime()) / (1000 * 60 * 60);

  if (diffHoras > 2) {
    // REGRA: Mais de 2h de antecedência = GRÁTIS
    return {
      revenueValue: 0,
      costValue: 0,
      tollValue: 0,
      tableApplied: "CANCELAMENTO ISENTO (>2h)"
    };
  } else {
    // REGRA: Menos de 2h ou já passou do horário = COBRA TABELA MÍNIMA
    return {
      ...financialData, // Mantém o cálculo da tabela "Cancelada" ou "100km"
      tollValue: 35.00  // Mantém o pedágio soberano
    };
  }
}
