  if (osData.status === 'CANCELADA') {
    // Busca a região baseada na origem (ex: Arujá/SP -> SUDESTE)

    };
  }

2. Por que o erro está ocorrendo (Análise da image_92a3ba.png):
Tempo de Operação: O sistema está contando 182.50h. Como a OS foi cancelada mas provavelmente ficou "aberta" no sistema, ele está tentando cobrar essas horas.

Divergência de Valores: Note que o sistema aponta uma "Tabela Oficial" de R$ 27.387,50. Isso acontece porque ele está multiplicando o tempo pela taxa horária, o que é um erro grotesco para uma OS cancelada.

Solução Visual: Ao aplicar a trava de cancelamento, os campos de "KM Real Executado" e "KM Previsto" devem ser forçados para 0.0 KM, zerando qualquer adicional.
