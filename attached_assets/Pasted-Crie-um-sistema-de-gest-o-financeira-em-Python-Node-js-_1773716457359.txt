Crie um sistema de gestão financeira em [Python/Node.js] integrado com a API do Asaas. O sistema deve ter as seguintes funcionalidades:Cadastro de Emitentes (Meus CNPJs): Criar uma tabela para gerenciar meus 3 CNPJs. Cada um terá sua própria 'API Key' do Asaas (ou uma única se for conta sub-filiada).Vínculo de Cliente: No cadastro de clientes, deve haver um campo para selecionar qual dos meus 3 CNPJs é o prestador de serviço responsável por aquele cliente.Boletim de Medição (BM): Criar uma tela de 'Nova Medição' onde eu insira os dados do serviço. Ao finalizar o BM, o sistema deve:Gerar a cobrança no Asaas via API.Retornar o Código de Barras e o QR Code PIX (usando o CNPJ do emitente vinculado como chave, se possível, ou o PIX dinâmico do Asaas).Vincular a Nota Fiscal de Serviço (NFS-e) com o valor exato do BM.Dashboard de Controle: Criar uma tela de listagem (tabela) com filtros por CNPJ emitente, exibindo:Status: Emitido, Pago (Baixado), Vencido ou Pendente.Valor da Nota Fiscal vs. Valor Recebido.Botão para baixar o PDF da Nota e o PDF do Boleto.Interface: Utilize uma interface limpa (Streamlit ou HTML responsivo) que funcione bem em modo Paisagem para gerar relatórios em PDF para os clientes, mantendo o cabeçalho padrão em todas as páginas.Regra de Negócio: Se o status no Asaas mudar para 'RECEIVED', o sistema deve atualizar automaticamente a baixa no meu banco de dados local."Como gerenciar os 3 CNPJs na APIComo o Asaas vincula uma chave de API a um CNPJ específico, você tem duas formas de fazer isso no código do Replit:Múltiplas Contas: Você cria 3 contas no Asaas e guarda 3 chaves diferentes nos Secrets do Replit (API_KEY_CNPJ1, API_KEY_CNPJ2, etc.). No código, você faz um if para decidir qual chave usar baseada no cliente.Conta de Parceiro (White Label): Se você tiver uma conta master, pode criar subcontas para seus outros CNPJs via API.Visualização de Dados (Dashboard)Para a tela de lista que você pediu, o Replit deve estruturar os dados assim:ClienteMeu CNPJ (Emitente)Valor NFVencimentoStatusAçõesCliente ATM SEGURANÇAR$ 5.00020/03PAGO[Ver Boleto] [Ver NF]Cliente BTORRES VIG.R$ 3.20025/03PENDENTE[Enviar Link]O Boleto e o PIXNa API do Asaas, ao criar a cobrança, você recebe o campo identificationField (Linha digitável) e pode fazer uma chamada adicional para GET /payments/{id}/pixQrCode para obter o QR Code e a chave copia e cola.Dica para o Replit: Peça para ele usar a biblioteca pandas para gerar o relatório de "valor por CNPJ". Assim você consegue ver rapidamente: "CNPJ X emitiu R$ 50k este mês, CNPJ Y emitiu R$ 20k".
