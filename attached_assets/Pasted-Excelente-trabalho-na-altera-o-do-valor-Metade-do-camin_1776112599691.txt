O "Gatilho" de Dependência (useEffect)No React, para que algo aconteça "sozinho" quando você muda um campo, o componente precisa estar a "ouvir" essa mudança. Se você seleciona "200KM", mas o sistema só calcula quando você clica em "Recalcular", significa que o gatilho automático não está configurado para o campo de KM.Como resolver:No arquivo do componente (provavelmente MissionForm.tsx ou BillingAudit.tsx), procure o useEffect que chama a função de cálculo. Ele deve incluir a variável da franquia/KM.TypeScript// Exemplo de como deve estar para ser automático:
useEffect(() => {
  if (formData.client_id && formData.origin_city && formData.selected_km) {
    handleCalculateFinancials(); // Chama a função de cálculo automaticamente
  }
}, [formData.client_id, formData.origin_city, formData.selected_km]); 
// ^ O segredo está aqui: o sistema "reage" quando esses 3 mudam.
2. A "Trava" do Valor Manual (tollValue === 0)Você mencionou que a condição tollValue === 0 continua ativa. if (isLogitechOperation && tollValue === 0) { ... }

// Use isto (Força o valor independentemente do que estava lá):
if (isLogitechOperation) {
  tollValue = 35.00;
  // Isso garante que a regra seja SOBERANA e automática.
