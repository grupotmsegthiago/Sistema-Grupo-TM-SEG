.env para frontend (opcional)
VITE_API_BASE=https://<seu-replit-url>
Como colocar para rodar no Replit
Crie um Repl Node.js.
Adicione as variáveis ​​de ambiente: SUPABASE_URL, SUPABASE_SERVICE_ROLE_KEY, SUPABASE_ANON_KEY.
Instalar:
Backend: npm i express cors @supabase/supabase-js node-fetch
Frontend: npm i react react-dom vite chart.js react-chartjs-2
Configure o script:
"start": "node server.ts" (use ts-node ou transpile para JS)
Alternativa: transpile TypeScript ou escreva server.js em JS puro.
Rode o backend e o frontend (pode separar em dois Repls ou servir o build do frontend via o mesmo Express).
Segurança
Nunca exponha SERVICE_ROLE no frontend.
Se quiser autenticar o acesso ao painel, adicione um token próprio no cabeçalho e valide no Express.
Limite CORS ao seu domínio do painel.
Sobre “por que meu banco caiu?”
Causas comuns: saturação de conexões, consultas pesadas sem índice, loops no Realtime, falta de recursos no plano, timeouts ou incidentes da plataforma.
Usar:
/api/status para verificar incidentes e saúde do REST.
/api/perf para ver picos de latência/erros.
Assessores para detectar políticas RLS/índices ausentes.
Monitore conexões e consultas lentas criando visualizações adicionais (posso fornecer SQL para pg_stat_statements, conexões por usuário, etc.).
